# Shape Sentinel – Prospective Memory Experiment

A neutral, browser-based shape identification task with low- and high-distraction trials and a prospective memory rule for blue triangles.

## Run locally

Open `index.html` in a browser, or serve this folder with a local static web server.

## Current data storage

Completed sessions are saved in the browser's local storage. Summary exports include participant details; trial-level exports use a participant ID. Contact details and research responses are stored under separate local-storage keys. Data is not sent to a server or shared across devices yet. Clearing browser storage can remove saved sessions.

A shared database and deployed site are needed before collecting participants across multiple devices.
